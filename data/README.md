# Datasets

This folder is gitignored. Run `make data` to populate it.

## PaySim (primary)

- ~6.3M transactions, 11 features, ~0.13% fraud rate.
- Source: https://www.kaggle.com/datasets/ealaxi/paysim1
- License: see Kaggle page; cite Lopez-Rojas, Elmir, Axelsson (EMSS 2016).
- Expected file: `data/paysim.csv`

## IEEE-CIS Fraud (cross-domain transfer)

- ~590K transactions, 393 features, ~3.5% fraud rate.
- Source: https://www.kaggle.com/competitions/ieee-fraud-detection
- Expected layout: `data/ieee_cis/{train_transaction.csv, train_identity.csv}`

## Africa-stress synthetic

- Generated by `scripts/prepare_data.py` from PaySim.
- Re-weights CASH_OUT and TRANSFER transaction types to up-weight CICO and
  account-takeover analogues.
- Reweighting parameters live in `configs/default.yaml` under `data.africa_stress`.

## Setting up Kaggle credentials

```bash
# put your kaggle.json under ~/.kaggle/
chmod 600 ~/.kaggle/kaggle.json
```

Then `make data` will download both datasets via the Kaggle CLI.
